# 记忆森林 · 家庭单词复习

一套适合手机使用的英语单词记忆应用，词表来自 `有道 260827.JPG` 中能够清楚确认的 82 个去重词条。

## 已实现

- 邮箱 + 密码创建家庭成员档案，你和孩子可分别使用各自邮箱。
- 单词、词性、IPA 音标、中文释义和逐词匹配的场景图片。
- 使用浏览器/手机系统英文语音朗读。
- 按 1、3、7、15、30、60 天复习，并显示遗忘倒计时。
- 每天最多安排 12 个新词，到期复习优先。
- 英译中、中译英、自查、薄弱词队列和掌握度统计。
- 可导入个人词表、导出进度备份。
- PWA：发布到 HTTPS 后可“添加到主屏幕”，核心界面和词表可离线打开。
- GitHub Actions 自动发布 GitHub Pages。

## GitHub Pages 账户说明

GitHub Pages 是静态网站，不能安全运行数据库。网页版会把邮箱账户、密码摘要和学习进度保存在当前手机或电脑浏览器中：

- 同一设备上可建立多个邮箱账户，进度互不混淆。
- 密码本身不会保存，只保存单向摘要。
- 换设备不会自动同步；请使用“导出进度”备份。
- 如果以后需要跨设备同步，可部署项目自带的 `server.js`，或接入 Supabase/Firebase 等后端。

## 本地运行

需要 Node.js 18 或更高版本：

```bash
npm start
```

打开 `http://localhost:8787`。

## 发布 GitHub Pages

1. 把本目录作为一个 GitHub 仓库，默认分支设为 `main`。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。
3. 推送到 `main` 后，`.github/workflows/pages.yml` 会自动发布。

## 隐私

不要把 `data/users.json` 提交到公开仓库；它已经由 `.gitignore` 排除。公开仓库中只包含词表和程序代码。
